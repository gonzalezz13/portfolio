## ✨ Sobre este proyecto

Quería un portfolio que no fuera solo una lista de enlaces, sino una página rápida, clara y fácil de recorrer desde el móvil. También quería salir de mi zona de confort y aprender React, así que he decidido utilizar esta herramienta para crear mi portfolio, he utilizado un diseño limpio y moderno, con una navegación sencilla e intuitiva. Con el portfolio quiero que la gente pueda conocer mi trabajo, mis habilidades y mi experiencia, y que a través de él puedan contactarme para futuras oportunidades.

## 🚀 Ejecutarlo en local
 
Necesitas [Node.js](https://nodejs.org) instalado.
 
```bash
# 1. Clona el repositorio
git clone https://github.com/gonzalezz13/portfolio.git
 
# 2. Entra en la carpeta
cd mi-portfolio
 
# 3. Instala las dependencias
npm install
 
# 4. Arranca el servidor de desarrollo
npm run dev
```
 
Abre la URL que aparece en la terminal (normalmente `http://localhost:5173`).
 
Para generar la versión de producción:
 
```bash
npm run build
```
